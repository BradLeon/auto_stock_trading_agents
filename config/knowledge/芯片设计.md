# L4 芯片设计层知识库

> 供 `structure_analyst` 打底。**只写年度级不变的东西**：价值链分工、技术演进方向、
> 护城河判据。
>
> **本文不写"谁排第几"，也不写市占数字。** 那是季度级判断，由「竞争位置证据」
> （产业链证据台账，见 `docs/CHAIN_EVIDENCE.md`）用本期财报原文给出。本文提供的是
> **排序的依据**，不是排序本身——L4 是全链条里格局变化最快的一层（越靠上游地位越稳，
> 越靠下游弹性越大），把排序写死在这里过时得最快。

## 一、价值链分工（谁在链条哪一环）

L4 只设计不制造，产能约束全部来自下游（L5 代工/封装/HBM）。**它自身没有产能瓶颈**——
出货受限时，受限的是台积电和存储厂，不是它的设计能力。这条判据决定了：L4 的供给侧叙事
（扩产、交期）几乎不携带关于 L4 自己的信息。

两条并行的产品路线，商业模式完全不同：

| | **外售通用加速器** | **定制 ASIC 设计服务** |
|---|---|---|
| 卖什么 | 完整芯片/整机系统 | NRE 设计费 + per-unit royalty + IP 授权 |
| 客户 | 云厂/AI Lab/企业，相对分散 | 少数几家超大规模云厂 |
| 收入形态 | 一次性硬件销售 | **一次性 + 持续性混合** |
| 链条利润 | 设计层拿走绝大部分 | 设计溢价消失，利润重心移向代工 |

**这张表是本层最重要的结构事实**：同样叫"芯片设计"，一美元终端支出流经这两条路线时，
留在 L4 的比例相差数倍。判断一家公司，先问它在哪条路线上、以及两条路线的收入结构。

还有一条常被忽略的分支：**网络芯片**（交换芯片、PHY、retimer/DSP）。它跟着机架规模走，
不跟着加速器份额走，所以在加速器份额此消彼长时可以是对冲项——同一家公司的两块业务
可能被同一个事件推向相反方向。

## 二、技术曲线（tech_tenor 的依据）

- **训练 vs 推理是两个不同的市场，不能合成一个"份额"。** 训练需要反向传播、梯度同步、
  大规模集群通信与成熟调试工具链，软件生态与系统级互联是硬约束；推理对生态的依赖弱得多，
  **ASIC 的替代首先发生在推理侧**。任何"ASIC 侵蚀 GPU"的判断，不区分训推就是错的。
- **ASIC 与云生态绑定，通用 GPU 不绑定。** 自研加速器只在自家云里跑，这既是它的天花板
  （无法外售），也是它的护城河（客户不会为跑自家芯片换云）。因此 ASIC 的渗透速度受限于
  **自家云的份额增长**，而不只是芯片本身好不好。
- **推理占比上升是本层最重要的 secular 变量。** 推理相对训练的比重越高，通用 GPU 的生态
  优势越被稀释。这条方向是确定的；速度不是。

## 三、护城河判据（moat_pricing 的依据）

本层的护城河类型不同，衰退速度差一个数量级。**先判类型，再判强度**——这是本文最该被
用起来的一条：

| 类型 | 壁垒来源 | 衰退方式 | 衰退速度 |
|---|---|---|---|
| **A 物理/工程极限** | 物理精度与系统集成，重建以十年计 | 替代技术路线绕过 | 极慢 |
| **D 工艺知识** | 长期积累的隐性制造知识 | 对手用时间和资本逐步追平 | 慢，但可追 |
| **C 客户锁定/定制化** | 与特定客户联合定义，跨代复用设计知识 | 大客户自研，或客户流失 | 慢（受设计周期约束） |
| **B 生态系统** | 开发者/工具链/框架围绕你构建 | **不被正面替代，被新范式整体绕过** | 最强时无敌，切换时最快 |

**抗打击能力粗排：A > D ≈ C > B。** B 型是本层的主流，也是最需要警惕的一型——它的强度
在巅峰期看起来最高，衰退时却最突然，因为生态资产在范式切换时是一次性贬值的。

按证据强度从硬到软的具体判据：

1. **软件生态的实际锁定深度** —— 不是"有没有生态"，而是**绕过它的成本还剩多少**。
   可观测代理：第三方编译器/中间层能否拿到接近原生的性能、顶级 AI Lab 的框架选择、
   新入行工程师的默认技能栈。**最硬，也最需要持续盯**。
2. **跨代设计关系的延续性** —— 定制 ASIC 侧最强的判据。合作了多少代、下一代是否还在。
   换供应商 = 重走一轮设计周期，这是时间壁垒不是技术壁垒。
3. **客户数量的方向** —— 定制路线上，客户数**在增加**是护城河变宽，停滞或缩减是客户自研
   在侵蚀需求。**方向比绝对数量重要**。
4. **系统级绑定（互联/整机）** —— 把芯片卖成机架，替换单元从"一颗芯片"变成"一套系统"。
   有效，但它依附于上面那条生态，生态松动时它一起松。
5. **性价比定位** —— **最软**。"比对手便宜且性能接近"不是护城河：定价权在对手手里，
   对手降价，这个位置的空间直接被压缩。

**衰退信号（要看方向，不要看当前状态）**：大客户自研芯片团队的规模变化；超大规模客户
是否把「训练用通用 GPU + 推理用自研 ASIC」公开定为标准架构；定制客户的代际是否中断。

## 四、常见误判

- **把"链条利润占比高"当成"护城河深"。** 高占比是当期定价权的结果，不是原因。真正要问
  的是：**客户为什么不能拒绝这个价格**——因为绕不过（护城河），还是因为暂时缺货（缺口）。
- **不区分训练与推理去谈份额。** 同一个"ASIC 替代"的读数，在训练侧和推理侧的含义完全不同。
- **把 ASIC 的成功读成 GPU 的失败。** 两条路线的终端支出总盘在增长；ASIC 放量的直接受益方
  除了设计服务商，还有代工方——**利润是迁移，不是消失**。
- **用 capex 判断本层。** L4 是轻资产层，capex/收入比常年个位数。它的 capex 变化几乎不含
  信息量；真正该看的是下游的产能与自身的收入结构。
- **把网络芯片和加速器混为一谈。** 前者跟机架规模走，后者跟份额走，可以同时一涨一跌。
