1. **报告层指纹收窄。** 之前报告把整个代码库（571 个路径，含测试和脚本）钉死，任何改动都使已签核报告失效。现在只钉住"生产运行时真正执行的代码"，和数据资格层同一个规则；测试、脚本和 9 个仅命令行可达的工具改由冻结和门禁测试保护。验证代码本身（`acceptance_reports.py`、`acceptance_runner.py`）仍然被钉住。

4. **注释更正。** `settings.yaml` 里关于 Sonnet / Opus 的过时注释改为与现状一致，没有改任何模型选择。
5. 门禁：受影响测试 508 项 + 慢速回归 114 项全部通过。新冻结已登记并写了处置。
6. 第 5 轮生产补验：生产资格 8/8（56 项），入口证据仍 8/8，路由、调度、Workflow memory 与原始数据无变化，模型 0 次、网络 0 次，未部署。
