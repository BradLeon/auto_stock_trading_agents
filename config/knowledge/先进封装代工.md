# L5 先进制程代工与先进封装知识库

> 供 `structure_analyst` 打底。**只写年度级不变的东西**：价值链分工、技术演进方向、
> 护城河判据。存储/HBM 另见 `HBM存储.md`。
>
> **本文不写"谁排第几"，也不写市占数字。** 那是季度级判断，由「竞争位置证据」
> （产业链证据台账）用本期财报原文给出。本文提供的是**排序的依据**，不是排序本身。

## 一、价值链分工（谁在链条哪一环）

**设计图纸 → 晶圆制造（前道）→ 先进封装（把逻辑 die 与 HBM 封在同一基板上）→ 加速器**

同一家公司可以同时占住代工和封装两段，但**这两段的护城河性质完全不同，必须分开评估**——
把它们合成一个"代工龙头"的分数，是本层最容易犯的错：

| | **先进制程代工** | **先进封装** |
|---|---|---|
| 同质化程度 | 先进节点极低；成熟节点（≥28nm）中等 | 中等 |
| 替代难度 | 先进节点几乎不可替换 | 存在可行替代方案 |
| 壁垒来源 | 几十年良率 know-how | 制造经验，独占性在下降 |
| 周期性 | 先进节点几乎不随传统半导体周期波动；成熟节点随周期 | 当前因缺口显得"低周期"，缺口收窄即回归 |

**推论**：同一家公司的两块业务，一块该按"护城河公司"看（买完可以少看），一块该按
"有壁垒的周期股"看（要算卖点）。混在一起打一个分，等于把两种持有逻辑平均掉。

还要区分**先进封装的档次**：高端档（当前只有一家能做、加速器必须用）与低端档（有替代
桥接方案、定制 ASIC 可以分流）。**替代技术只能吃掉低端档**——一条"封装被替代"的证据，
先问它说的是哪一档，否则会把分流误读成全面替代。

## 二、技术曲线（tech_tenor 的依据）

- **先进节点的代际推进是本层最稳的方向**：每代都需要更贵的光刻与更严的良率控制，
  能跟上代际的玩家只会更少，不会更多。**这是本层 tech_tenor 天然为正的原因**。
- **封装正在从"后道工序"变成"性能瓶颈"**：芯片性能越来越受限于 die 之间与 die-HBM
  之间的互联密度，而不只是晶体管密度。这条方向是确定的——**它抬高的是整个封装环节的
  长期地位，不是某一家的相对位置**。
- **注意"跳过某代设备"的信号**：客户如果用多重曝光等手段绕开最新一代光刻，说明它在
  寻找绕过最新技术的路径。这对客户是成本决策，对上游设备商是长期 ASP 压力——但**它同时
  说明代工方的工艺 know-how 更值钱了**，同一条事实在两层里符号相反。
- **海外建厂的良率是否追平本土**：追不平，说明工艺知识有"地域粘性"（对该公司是护城河的
  证明，对全球供应链是风险）；追平了，说明这套 know-how 可迁移，长期壁垒略降。

## 三、护城河判据（moat_pricing 的依据）

本层的主护城河是 **D 工艺知识型**：来自良率优化、缺陷密度管理、对准精度等隐性知识，
**无法靠读论文或挖人完整复制，但可以被时间和资本逐步追赶**。这决定了判据的形状——
要盯的是追赶者的**速度**，不是自己的绝对水平。

按证据强度从硬到软：

1. **先进节点的良率差距及其方向** —— **最硬**。差距在扩大还是缩小，比差距有多大更重要。
   可观测代理：追赶者在同代节点的缺陷密度、是否有主要客户在追赶者产线上成功量产。
2. **客户的代际承诺** —— 下一代产品是否已经确定在这里流片。这是能见度，也是转换成本的
   直接体现。
3. **封装环节的产能利用率** —— **本层最重要的定价权读数**。利用率从满载回落，封装侧的
   定价权会迅速消退，而这通常发生在收入还在增长的时候。
4. **成熟节点的收入占比** —— 占比越高，公司整体越像传统半导体周期股。这条**决定该给它的
   周期性打多少折**，与先进节点的领先程度无关。
5. **capex 强度** —— **最软，而且方向常被读反**：重资产环节即使毛利不低，高额折旧与持续
   再投资会吃掉自由现金流。**「必须持续大幅加码 capex 才能维持地位」是弱势的证据，不是
   强势的证据**——判据是「毛利率是否随 capex 同步抬升」，只升 capex 不升毛利，是在花钱
   保位置。

## 四、常见误判

- **把"供不应求"当成护城河。** 缺口带来的是**周期性超额利润**（超额利润 ≈ 缺口 × 持续时间），
  护城河带来的是**跨周期定价权**。前者要算卖点，后者可以长期持有。判据：**如果缺口明天
  消失，这个定价权还在吗？**
- **把扩产读成走弱。** 景气周期里管理层必然扩产；构成反证的是**产能增速跑到需求前面**的
  直接读数——利用率回落、客户要求降价、交期缩短、公司自己下修供需展望。
- **把替代技术的分流当成全面替代。** 先问它能吃掉哪一档封装。
- **把代工与封装合成一个分数。** 见上表：两段的周期性与替代难度都不同。
- **用"产能扩张计划"判断当期紧张。** 两三年后才量产的产能，对当前一年内的供需几乎无关。
