### NVDA Q3 FY2027

- 共识：EPS 2.46983（2.34~2.7）　营收 108972821930.0

**叙事：** NVDA仍是AI加速计算的绝对龙头，Q3 FY2027的核心不是收入能否超过市场共识的1,089.7亿美元，而是数据中心收入与次季指引能否证明增长仍主要受供给而非需求约束。Q2收入已达962.2亿美元、毛利率约75%，显示GB200/GB300系统放量与软件生态的定价权仍强；TSM CoWoS、HBM供给松动将直接转化为更高出货和指引上修。管理层此前称需求远高于可交付增速，且供应商采购承诺由1,190亿美元跃升至2,790亿美元，主要针对存储，支持订单可见度，但也使市场会严查库存、HBM成本和供应链兑现。主权AI、推理负载及Groq技术整合提供超大云厂商之外的增量来源；中国H20/合规版的许可、产品与收入进展则仍是政策驱动的非线性变量。

利润率是本季估值分水岭：高端系统爬坡、HBM价格与产品组合将决定约75%的毛利率能否守住；市场已知后续季度毛利率可能由约74%降至约71.5%，因此可接受“规模换取短期稀释”，但不能接受毛利率下调与收入指引同步疲软。更重要的新风险是需求融资质量：AI基础设施融资平台、租赁承诺、收入担保与残值支持有利于释放订单，却把部分需求确定性转换为信用、回收与或有负债风险。PEAD画像偏高：这是典型的“小幅beat也可能卖出”的股票；若收入和EPS仅小幅超预期、次季指引未显著上修，或管理层强调供给、HBM成本、融资敞口及中国限制，便容易出现beat-but-drop。反之，供给扩张带来交付上修、Blackwell放量超预期且毛利率压力可控，才足以支持财报后上行漂移。

**关注排序：**
1. 次季收入指引及数据中心收入增速——这是AI资本开支周期与全市场风险偏好的核心锚，必须显示供给释放正在转化为可交付收入，而非仅确认需求旺盛。
2. GB200/GB300出货爬坡与CoWoS、HBM供给——当前主要瓶颈在供给；交付节奏、组件取得与客户部署决定收入超预期的幅度和持续性。
3. 毛利率指引、HBM成本与系统产品组合——市场可容忍过渡期稀释，但需要相信约75%毛利率向约71.5%的下行是可控且暂时的，而非定价权或成本结构恶化。
4. 收入与EPS相对共识的超额幅度——共识收入为1,089.7亿美元、EPS为2.46983；单纯小幅超过不足以驱动上涨，关键是能否触发后续年度预测上修。
5. 供应商承诺、库存与营运资本——采购承诺大幅增至2,790亿美元、库存此前已升至315.8亿美元；这些数据既验证长期供给锁定，也会测试是否存在需求错配或库存风险。
6. AI基础设施融资、租赁和残值支持敞口——融资能扩大客户购买力，但市场会关注担保、租约转移、信用增级及现金流/资产负债表影响，防止销售质量被融资风险掩盖。
7. 主权AI、推理与中国合规产品——前两者决定第二增长曲线的广度；中国政策、H20或合规版产品的许可和销售变化则可能显著改变区域收入预期。

## 四、本次发现的问题

1. **共识与财报期错位**：准备任务取的是供应商“当前季”共识，没有核对它属于哪个财报期。财报发布后到供应商滚动之前，会把下一季共识贴到上一季标签上，导致事件评审出现假的重大意外。
