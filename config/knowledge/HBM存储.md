## 一、价值链分工（谁在链条哪一环）

HBM 价值链：**DRAM 晶圆 → TSV 堆叠/键合 → 与逻辑芯片的先进封装(CoWoS) → 加速器**。
利润集中在 **DRAM 良率 + 堆叠工艺 + 客户认证资格** 三处。HBM 不是通用商品内存：
它按代际与单一客户联合定义，**通过认证 = 拿到未来 1-2 年的份额**，认证是最硬的护城河。

## 二、技术曲线（tech_curve）

- **代际**：HBM3 → HBM3E（8/12 层）→ **HBM4（2026-27 上量，接口位宽翻倍、
  可能引入定制 base die）** → HBM4E。每代堆叠层数与键合难度上升，良率是分水岭。
- **定制化趋势**：HBM4 起 base die 走向客户定制，**加深与单一客户的绑定**——
  对已认证方是护城河加深，对追赶方是更高的进入门槛。
- **供给约束链**：HBM 产能同时受 DRAM 晶圆、TSV/键合设备与 CoWoS 封装位三者约束，
  任一环松动都会改变"紧张"叙事，**不能只看某一家的扩产公告**。

## 三、三家结构位（SK Hynix / Micron / Samsung）

### SK Hynix（SKHY / HY9H / 000660.KS 同一经济实体）
- 分工：HBM3E 先发，与头部加速器客户深度绑定，堆叠良率领先。
- 护城河：**先发认证 + 良率 + 客户联合定义**；风险是单一大客户集中度高。
- 久期：HBM4 世代仍是默认主供，但**领先幅度是本设计要持续证伪的对象**（见下）。

### Micron（MU）
- 分工：HBM 第二供，美国本土产能与政策位置有利；整体 DRAM 周期弹性大于 HBM 纯度。
- 护城河：客户多元化诉求下的"必要第二供"，但认证进度落后于先发方。

### Samsung（005930.KS）
- 分工：垂直整合最全（存储 + 代工 + 封装），HBM 上曾落后，HBM4 世代为追赶关键窗口。
- 护城河：**规模与垂直整合**；变量是核心客户认证能否通过——一旦通过，
  份额转移的速度会快于产能建设速度。

### 长鑫存储 CXMT（非上市）
- 国产替代变量。量产成功会冲击**整层的定价权**，而非某一家的份额。
- 系统里只作为**减仓侧信号**存在（无可交易标的，见 docs/CHAIN_EVIDENCE.md 第八节）。

## 四、给评分的提示（moat_pricing / tech_tenor）

- **认证 > 产能 > 资本开支**：证据强度依次递减。竞争者扩产**不等于**先发方失份额；
  只有份额、认证、ASP/毛利率的直接读数才说明位置变化。
- **ASP 与毛利率是定价权的直接读数**：HBM 售罄但 ASP 走平，说明稀缺溢价已被定价。
- 三家同时扩产 = 层级供给转松（common），**不是**某一家的相对优势变化（relative）。
