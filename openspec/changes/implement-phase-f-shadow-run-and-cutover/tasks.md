# Tasks

任务编号沿用旧规划 `refactor-workflow-dataflow-architecture` 第 11 节：`F.0.x` 为 Phase F 前置接收，`11.x` 为实施段，便于与既有验收材料对照。分组顺序即 design.md 的 Migration Plan 阶段顺序；每组自带其测试与文档，不把测试与文档延后到末组。

**全程约束**：本阶段不重建数据平台、不重复全量采集、不改动 A–E 已验收契约与门禁标准；真实 live route 切换保持锁定，只交付门禁、runbook 与演练；未取得资格的消费者保持稳定旧路由。
