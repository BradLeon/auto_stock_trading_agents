# Tasks

> 第 1 组需要用户本人操作（安装与凭据）；第 2–3 组可先在只探测模式下验证。

## 1. IBC 安装（用户操作）

- [ ] 1.1 用户下载安装 IBC，填写 `~/IBC/config-live.ini`（实盘账号、7496 端口），`TWS_MAJOR_VRSN` 与已装 TWS 一致。验证：用户手动执行启动脚本，TWS 经 IBC 登录成功，手机确认 2FA 后 7496 可连。

## 2. 启动与守护脚本

- [ ] 2.1 编写本仓的 IBC 启动脚本（参照 `start_tws.sh`，只支持 live）：已有 TWS 进程时不重复启动。验证：在 TWS 已运行时执行，脚本退出且不启动第二个实例。
- [ ] 2.2 编写守护检查（D2、D3、D5）：
  - 端口加只读握手探测；
  - 按顺序升级恢复，重启有上限；
  - 识别“等待 2FA”状态；
  - 日志脱敏。

  验证：单测或脚本自测覆盖握手成功、端口可达但握手失败、端口不可达、重启达上限、等待 2FA、日志脱敏六种情况；只探测模式下对真实 TWS 执行一次，判定为可用。
- [ ] 2.3 告警接入现有飞书机器人通道，覆盖“已恢复”“需要人工”“等待 2FA”三类。验证：用测试模式各发一条，内容不含凭据。
- [ ] 2.4 在 `docs/OPERATIONS.md` 增加“TWS 托管与恢复”一节：安装、配置位置、守护行为、手动接管方法。验证：按文档能完成一次手动接管。

## 3. 部署与观察

- [ ] 3.1 部署 `com.ats.tws-guard` launchd 任务，每 5 分钟一次。验证：`launchctl list` 可见，日志每 5 分钟一条心跳。
- [ ] 3.2 观察一次真实的每日重启（或人为退出 TWS 演练一次）。验证：10 分钟内发起恢复，日志与告警完整；clerk-daily 当天正常。
