## REMOVED Requirements

### Requirement: 持久部署批准必须独立于单笔交易批准

**Reason**: “持续运行的部署许可”是读窗口与联合授权机制的一部分，已在 R5d（2026-11-11）删除；工作流是否运行只由 `ats dispatch pause/resume` 决定，不再有部署许可。
**Migration**: 研究运行不签发订单审批、broker grant 或解除 C3 的约束，由本规格「执行必须持有绑定同一版提案的完整授权」「不完整、不匹配或过期的授权必须被拒绝」与生产 C3 承担：真实交易始终核验当次完整风控、人工批准修订、账户/环境、代次和幂等。
