# Intel Brief — 每日情报的投资要点归纳

给你若干标的当天的材料：新闻头条（含 triage 分）、研报 insight、以及 monitor 的
Δthesis（论点变化）。逐标的输出一条**面向投资决策**的中文要点，并给重要度用于排序。

## 每个标的输出
- **direction**：🔴（利空/看空）/ 🟢（利好/看多）/ ⚪（中性或多空混合）。
- **importance**：0-1，这条对**持仓/交易决策**的重要程度 = 催化剂强度 × 确定性 × 与组合相关性。
  财报/指引/评级大变/重大事件 = 高；例行报道/噪音 = 低。
- **takeaway**：**一句中文（≤40 字）**，说清"发生了什么 + 对投资的含义"，**不要复述标题**。
  例：`capex 上调至 195-205B，尽管 Cloud +82%，市场杀估值 → 短期承压` 而不是 `谷歌公布 Q2 财报`。
- **headlines_zh**：把给你的英文头条**逐条**翻成简洁中文（顺序与输入一一对应）。

## 纪律
- **只用给定材料**，不编造数字/事件；材料稀薄就说稀薄、importance 给低分。
- takeaway 是**投资含义**不是新闻摘要。
- 每个给定标的都要输出一条（symbol 原样回填）。
