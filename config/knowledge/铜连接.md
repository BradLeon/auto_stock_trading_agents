# 铜连接子层知识库

> 供 `structure_analyst` 打底。**只写年度级不变的东西**：链条位置、技术演进方向、
> 护城河判据。
>
> **本文不写"谁排第几"，也不写市占数字。** 那是季度级判断，由「竞争位置证据」
> （产业链证据台账）用本期财报原文给出。本文提供**排序的依据**，不是排序本身。

## 一、铜连接在 AI 机架里的位置

- **DAC（无源铜缆）**：最短距、最便宜，速率升高后可达距离骤降。
- **AEC（有源电缆）**：内置信号调理（retimer/DSP），把铜的可达距离往外顶，在 DAC 够不到、
  光又太贵/太耗电的**机架内中短距**卡位。
- **retimer/DSP**：独立的 IP 层，同一套能力可以向**光** DSP 延伸——这是判断一家铜连接
  公司久期的关键分叉点。

## 二、技术曲线（tech_tenor 的依据）

这是全链条里**唯一一个技术方向明确不利**的子层，判据因此与别处相反：

- **近期真实**：机架内 NVLink 铜背板/铜缆密度随 GPU 机架规格暴涨，AEC 替代 DAC，
  近端 TAM 是真的，不是炒作——**高增速有基本面支撑**。
- **secular 尾险**：每升一代 SerDes，铜 reach 缩短；LPO / CPO / 光进封装长期可能连机架内
  也蚕食。**铜连接是"防守/过渡"技术，久期短于光模块。**
- **缓释项**：向光 DSP / retimer 延伸（LPO 同样需要 DSP），部分对冲铜被替代的风险。
  机架内铜密度短期也难被完全取代（成本与功耗仍占优）。

**判据**：`tech_tenor` 打折是这个子层的结构性特征，不是对某家公司的判断。区分度应该来自
"这家在多大程度上已经跳出纯铜"——延伸到光 DSP 的程度越深，折扣越小。

## 三、护城河判据（moat_pricing 的依据）

按证据强度从硬到软：

1. **SerDes / DSP 的 IP 深度** —— 这是唯一能跨越铜光两侧的资产，也是最难复制的。**最硬**。
2. **客户分散度** —— 本子层客户天然集中在少数超大规模云厂，所以这一条的**扣分权重比
   别的子层更高**：一个客户的架构选型变更就能改写全年。
3. **在下一代规格里的设计导入** —— 已经被写进下一代机架设计 = 拿到 1-2 年能见度。
4. **产能与交付规模** —— **最软**。线缆组装环节壁垒有限。

## 四、常见误判

- **把增速当久期。** 这个子层最典型的陷阱：增速最高的时候，恰恰是被替代压力最大的
  时候——因为 TAM 爆发来自机架内密度暴涨，而密度暴涨正是光进封装最想解决的问题。
- **把"铜没死"当成"铜会赢"。** 机架内铜短期不可替代是成本问题，不是技术优势；
  成本曲线会移动。
- **忽略 IP 的跨侧价值。** 只看铜业务会低估那些 DSP 能力已经在向光迁移的公司——
  它们的久期风险和纯线缆厂不是一回事。
